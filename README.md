# Открытка «С Днем Рождения»

Милая одностраничная открытка: закрытое письмо → открытие с сердечкамии наездом камеры → само письмо с бесконечной бумажной лентой.


## Запуск локально

Вариант 1: просто двойной клик по index.html — всё работает.Вариант 2 (рекомендуется): в папке проекта выполнить    python -m http.server 8000и открыть http://localhost:8000


## Публикация на хостинге

Скопируйте ВСЕ файлы и папки в корень сайта (обычно public_html).Также подходят: Netlify Drop (перетащить папку на app.netlify.com/drop),GitHub Pages (положить в корень репозитория, включить Pages).

## Советы:

PNG с прозрачным фоном; dog.png и rabbit.png лучше рисовать смотрящими вправо (влево сайт зеркалит их автоматически).Пока файлов нет — сайт сам показывает встроенные плейсхолдеры.

### Замена картинок

Положите свои файлы в img/ с этими именами:
- envelope.png — закрытое письмо
- envelope_open.png — открытое письмо
- dog.png — собачка для фона
- rabbit.png — зайчик для фона
- rabbit_sticker.png — стикер в конце письма
- heart.png — сердечко

### Замена текста

Откройте index.html, найдите блок «ТЕКСТ ПИСЬМА» и замените абзацы на свои. Подпись в конце — строка с классом end-sign.
